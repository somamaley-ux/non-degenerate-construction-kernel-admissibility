# Downstream compatibility and theorem routing

Existing import paths and declaration signatures are retained. Use `import AASCKernelPaperClean` for the complete supported reference surface, `import KernelReference` for the new mathematics, or a specific module when a smaller dependency is preferable.

| Existing surface | Exact meaning retained | Current route |
|---|---|---|
| `IncidenceSystem.Nondegenerate` | A carrier/query pair with no incident result exists. It does not assert positive incidence. | `Foundation.HasActualIncidence`, `HasFailureBoundary`, and `HasBothWitnesses` name the three distinct requirements. |
| `TargetAdequacy.Regime.Nondegenerate` | Both a standing use and a nonstanding use exist. | `HasSuccessfulUse`, `HasFailedUse`, and `legacy_regime_nondegenerate_iff_both` expose this meaning. Local actual standing does not require both polarities. |
| `TargetAdequacy.Redescription` | Explicit endpoint, target, and verdict preservation data. | `DependentConservation` derives result agreement from the independently fixed bearer/query and the two incident outputs. |
| `Manuscript.ActIdentity` | The original represented equivalence includes verdict agreement. | `Foundation.OriginalPerformance` identifies occurrence, material, conditions and target before verdict; result agreement requires its separate determinate incidence premises. |
| `KernelRoleOmission`, `no_self_faithful_counterexample` | Results about their explicit represented predicates and packages. | Functional deletion is tested against the independently required work in `Foundation.ObservationWork`; the constitutive four-role minimality argument is in the paper. A failed ordinary use is not deletion of a role. |
| `no_faithful_lower_generator` | Exclusion of its explicitly packaged basis/generation/fidelity data. | `Authorization.finite_authorization_cut` and `governance_free_has_no_warrant` prove the finite interpreted dependency argument. |
| `no_intermediate_status` | A classical admitted-equivalent/not-admitted-equivalent split. | Canonical status, semantic conservation, and exact observer descent state the relevant stronger results with their hypotheses. The raw API is not asserted to have only two arbitrary profiles. |
| `constructional_report_preservation` | Consequence of an explicit report-support premise. | `Authorization.report_from_local_evidence` derives support and standing from complete ancestor coverage, local checks, and sound local rules. |
| `main_fixed_domain_exhaustion` | Original represented assembly with standing-preservation premise. | See the reference proof map for current manuscript Theorem 7.1's several components and its constitutive argument. |

No downstream theorem changes merely because the new files are imported. A downstream application should use the current route when it claims the corresponding stronger derivation, and discharge the stated original-domain premises. Classification uniqueness does not imply a unique occupant; a finite authorization cut does not establish every possible infinite argument; invariance under all carrier permutations is not inferred from object determinacy alone.
